Broken Object Level Authorization

Finding ID FINDING-001
Category BOLA
Severity HIGH
Endpoint GET /identity/api/v2/vehicle/{vehicleId}/location
Confirmed True

Description

An authenticated user was able to access a vehicle object belonging to another authorization context.

Impact

An attacker can access another user's vehicle data, including vehicle location and associated user information.

Evidence

Remediation

Enforce server-side object-level authorization on the vehicle endpoint. The API must verify that the authenticated user owns or is explicitly authorized to access the requested vehicle before returning its data.
